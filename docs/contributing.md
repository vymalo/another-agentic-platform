# Contributing

Start with [`CONTRIBUTING.md`](https://github.com/vymalo/another-agentic-platform/blob/main/CONTRIBUTING.md): how to claim an issue, build, test and open a pull request. It
stays at the repository root and is linked from here, not copied, so there is one version to keep true. Report a
vulnerability through [`SECURITY.md`](https://github.com/vymalo/another-agentic-platform/blob/main/SECURITY.md), never a public issue. The product
roadmap is the system's [`ROADMAP.md`](https://github.com/vymalo/another-agentic-system/blob/main/ROADMAP.md). Coding agents work from
[`CLAUDE.md`](https://github.com/vymalo/another-agentic-platform/blob/main/CLAUDE.md).

Writing the docs themselves — the architecture's editing rules, the site and its gates — is [Writing docs](writing-docs.md).
