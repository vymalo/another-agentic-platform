# Contributing

Start with [`CONTRIBUTING.md`](https://github.com/vymalo/another-agentic-platform/blob/main/CONTRIBUTING.md): how to claim an issue, build, test and open a pull request. It
stays at the repository root and is linked from here, not copied, so there is one version to keep true. Report a
vulnerability through [`SECURITY.md`](https://github.com/vymalo/another-agentic-platform/blob/main/SECURITY.md), never a public issue. Coding agents work from
[`CLAUDE.md`](https://github.com/vymalo/another-agentic-platform/blob/main/CLAUDE.md). The full Contributing section is planned (ANR-936).
